# Maintaining the ppk2lab repository

Repo working rules live in `AGENTS.md`/`CLAUDE.md` and always apply: no
copied third-party source, no firmware binaries, no implicit hardware state
changes, no external publishing without explicit user authorization.

## The committed frontend build

`src/ppk2lab_web/static/` holds a build artifact that is committed and shipped
in the wheel, so that installing from PyPI never needs a Node toolchain. Three
consequences for any audit:

- **Never hand-edit those files.** They are regenerated by `npm run build` from
  the sources in `webui/`; an edit there is lost on the next build and is
  invisible in review.
- **The console cannot be run in `0.4.0`.** There is no server, no `web`
  extra, and no subcommand for it. Do not tell anyone to start it.
- The bundle contains third-party code that no Python metadata mentions; gate 6
  covers it.

`webui/README.md` documents the frontend for someone changing it. Do not copy
its content here — link to it.
